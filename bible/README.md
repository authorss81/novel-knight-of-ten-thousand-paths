# Novel Bible

The canonical bootstrap files are:

- `premise.md` — logline, protagonist engine, central mystery, and final target.
- `world.md` — Neyra’s geography, history, factions, the seven erased villages, ordinary life, the bell’s provenance, and path worlds.
- `characters.md` — protagonist, cast, the erased as records, antagonist ladder, voice rules, cast discipline, and survival commitments.
- `power-system.md` — oathcraft, practitioner types, who can open a road, custody protocols, stages, costs, failure modes, and the System voice.
- `themes.md` — authority, consent, grief, infrastructure, memory, and the planned thematic answer.
- `terminology.md` — calendar, currency, measure, custody titles, names, and language conventions.

Three quick rules for a writer who has only five minutes:

1. **No path is a reset.** A crossing changes the world permanently. Death inside a path is permanent for that version of the person.
2. **Aren is never required.** Local custodians open roads. If a scene can be solved by Aren personally doing the only possible thing, it is a scene that should not exist.
3. **Every cost is concrete.** Roadmarks, fever, lost time, a scar, a closed market, a relationship that cannot return to its old shape.

No chapter prose is generated during the bootstrap phase. Read these files before planning the first volume or writing the first batch. `outline/series.md` holds the 18-volume arc, a per-volume knowledge-control table, and a pressure rotation; `outline/ending.md` holds the finale and the setup-to-payoff map.
