# Novel Bible

The canonical bootstrap files are:

- `premise.md` — logline, protagonist engine, central mystery, and final target.
- `world.md` — Neyra’s geography, history, factions, cultures, and path worlds.
- `characters.md` — protagonist, supporting cast, relationships, antagonist ladder, and survival commitments.
- `power-system.md` — oathcraft, path entry, persistence, capacity, carryover, costs, stages, and System voice.
- `themes.md` — authority, consent, grief, infrastructure, memory, and the planned thematic answer.
- `terminology.md` — canonical names, places, terms, and language conventions.

No chapter prose is generated during the bootstrap phase. Read these files before planning the first volume or writing the first batch.
