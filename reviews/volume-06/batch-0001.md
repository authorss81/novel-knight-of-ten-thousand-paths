## What this batch adds to the pattern

The README records eleven reviews in which no review found a plot defect in delivered prose, and this is the twelfth and the thirteenth data point and they agree: **every finding in both reviews that changed a chapter was a continuity, arithmetic, punctuation, voice or count slip, and every finding about a record was a record about a record.** But this pair adds a twelfth class, and it is the one this file exists for. **Review 1 was not wrong in its reasoning. It identified the plan violation, it named it as the finding a later batch would have inherited, it gave the right remedy, and it wrote the remedy down in bold in a file a later phase would read. The remedy was never applied, and the finding about it was itself never written anywhere a second reader could find.** So the new class is not an unmeasured number and it is not a false claim about an artifact. **It is a correct repair that was never performed, described in the past tense, in a file that the next phase inherits as fact.** Every one of the five blocking findings is that, and one of them is a plan violation. **The rule that follows is the one this project already half has — go and look at the page for every figure you print — with the second half now written down: a repair record is not evidence, and a reviewer must re-run a repair pass against the text, by string and not by line number.** A pass that trusts its own ledger will find its own ledger correct and the page wrong, and it will report that it found nothing.
