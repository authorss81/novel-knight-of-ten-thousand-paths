**The pattern worth naming:** across six batches, no review has found a plot defect in the delivered prose. Every finding that changed a chapter was a continuity, arithmetic, formatting or voice slip, and every finding about a record was a record about a record. The two files above marked as gap records are the honest cost of `logs/` being gitignored: the disposition survived because it was written into `state/batch-summaries.md`, and the reasoning did not. **What Batch 0009 adds to the pattern is the second kind of record defect, and it is the more expensive one: a state file asserted that the next phase's prompt existed, and the next phase's prompt did not exist.** A false claim about an artifact is worse than a missing artifact, because the missing artifact is visible and the claim is not.
