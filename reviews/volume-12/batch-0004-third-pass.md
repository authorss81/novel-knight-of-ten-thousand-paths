## The two instruments that were wrong before they were right

**The money parser was blind in the same direction three times and the fix is the one this repository has now written down four times.** A parser anchored on `pence is` that rejects the *a hundred and X* spellings returns **19 prior instances against 171** and reports four of this block's ten columns where there are ten. **And a parser that splits on hyphens before parsing, then hands the already-split token to a function that expects a hyphen, throws on every hyphenated total and the exception is swallowed** — which is how the same ten columns came back as four. Both were found by printing the instance count beside the set size, and both are now correct. **The prior set is 159 distinct on the house form and 155 on an independent route, union 185, and every one of the block's ten is clean against all three.**

**The duplication instrument reported a boolean where a run was needed, and a re-run of it is not a re-check.** A seed-and-extend matcher returned no result at all on this block's shape, and a first 12-gram index reported a 27-word run against 0580 and a 15-word run against 0580 for two chapters where the volume's own recurring frame sentence is the longer shared string. **The instrument was then rebuilt to report a run length with the file it matched, which is what found the 82.**

**A coda counter built on one phrase is no counter.** The phrase-anchored enumeration counter reported mismatches on 27 of the 30 numeric claims across this block and was wrong every time, because these codas build their claims on *figures of*, *separate counts of* and *are N figures of* in different sentences. **All 30 were then counted by hand, item by item, and all 30 foot.**
