## What this pass adds to the pattern

**The pattern this project has kept paying for is a figure that was measured once, written down, and copied. This pass adds the case in which the copy is the error and the original is right — in all three count findings.** The reporting clause was printed as thirty and eighty-four in the handoff file and as thirty-one and eighty-five in the two files that had it right. Chapter 347 was printed at 1,971 in the handoff file and 1,841 in two others, against a block total that only 1,841 produces. The Saturday and market-day counts were the prompt's two and three in three files against the page's three and five. **In every case the number that had travelled is the number that is wrong, and `state/current.md` is the file in which all three landed, because `state/current.md` is the file a phase reads first and trusts.** That inverts the usual direction and it has one practical consequence: **a ledger cannot be checked against itself, and a close that audits a volume by comparing its own state files against each other will find nothing.** The instrument that caught all three was a second count on the page, by somebody who had not written the figure down.

**And the second thing this pass adds is a new class of defect, and it is the one worth keeping: a repair that changes a figure without counting the thing the figure is about.** The block found a speech-length figure that did not foot, moved it from seventy-seven to seventy-six, recorded the move in four files, and shipped a figure that was wrong by eighteen words. **On the page that repair is indistinguishable from no repair, and no instrument in this project can see it, because the repaired text is not a duplicate, not a mismatch and not a barred token — it is a sentence that reads correctly and is about the wrong number.** Volume 01 Batch 0004's second review found a repair pass that had left five of its own findings in place; this is the same failure wearing a different hat, because in both cases the pass believed it had counted. **The rule is unchanged and now has a second reason: a figure is counted by counting the thing it is about, and a digit changed in a number is not a count.**
